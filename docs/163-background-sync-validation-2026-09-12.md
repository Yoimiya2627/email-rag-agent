# 163 后台同步与本地检索（2026-09-12）

本轮在现有只读 IMAP 接入上补充历史回补、持久化后台调度、邮件状态核对和独立全文检索。没有修改远端邮件，没有启用真实邮件的 DeepSeek 问答，也没有将真实邮件混入样例 RAG 索引。

## 使用方式

1. 在「163 邮箱 · 本地收取与解析」选择账号，测试连接并读取文件夹。
2. 默认选中收件箱、已发送和可选的归档/自定义文件夹；垃圾、已删除、草稿默认排除，可以手动调整。已保存自动同步设置时沿用原范围。
3. 展开「自动同步与历史回补」，启用后台自动同步，设置检查间隔并保存。推荐间隔 5 分钟、单批 100 封。
4. 历史邮件分批处理，文件夹内优先较新的 UID，文件夹之间轮转分配名额。有待回补且本批无失败时，5 秒后继续；补齐后按配置间隔检查。
5. 用「搜索本地真实邮件」搜索主题、地址、正文及已提取附件文本，可按文件夹、未读和星标过滤。此搜索完全在本地 SQLite 执行，不调用模型。聊天框仍使用原先独立的问答索引。
6. 「暂停自动同步」阻止后续批次，当前正在执行的批次继续完成；需要立即停止当前任务时，在后台任务面板中停止该任务。

网页关闭后，API 服务运行期间仍会定时同步。电脑休眠或关机时不会收取邮件，服务恢复运行后会检查已到期任务；本轮没有安装 Windows 开机自启动服务。

## 数据与同步边界

- 原始 MIME、解析结果、全文索引与账号隔离存储；账户授权码继续使用 Windows 用户加密保护。
- 本机使用 `E:/email-agent-runtime/imap` 存邮件及索引，调度状态位于 `E:/email-agent-runtime/mail-schedules.sqlite3`。没有新增环境依赖或安装到 C 盘。
- 每轮核对所选文件夹的 UID 与 FLAGS；已下载且解析版本未变化的邮件不重复下载正文。已读、星标、移出文件夹及远端不再存在的记录反映到当前本地视图，原始历史记录保留。
- 因为状态核对需要列举 UID 和 FLAGS，大邮箱的检查成本仍随所选范围增长；这里的「增量」指正文下载，不是每轮零成本扫描。
- 任务意图在提交前持久化，通过已有任务 ID/操作键恢复，避免重复提交。失败有退避；连续失败达到 8 次后暂停，检查授权和网络后重新保存设置恢复。
- 完整性仅针对 IMAP 当前可见的所选文件夹。163 网页端若限制客户端收取范围，需要核对「收取全部邮件」设置，不能将 IMAP 数量直接等同于网页邮箱总量。
- 默认搜索最多显示 20 项，接口最多 50 项；最多 32 个查询词、500 个字符，并有时间和文本预算。附件只搜索已提取部分；提示不完整的附件不声称完整覆盖。
