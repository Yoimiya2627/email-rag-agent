# 邮件助手界面精简

本次按“聊天为主，需要时打开邮件”的使用方式调整现有 Streamlit 前端。

- 浅色窄侧栏保留助手对话、查看邮件、邮箱设置三个入口；账号选择放在底部，地址和管理入口收进账号详情。
- 新对话把简短引导和大输入框放在一起；首次发送后移除引导，输入框固定在底部。会话内容、模式选择、任务恢复和来源核对沿用原流程。
- 会话记录放在“会话”菜单，模式和高级工具再展开查看。首页保留一行真实范围说明：对话使用导入资料，真实邮件尚未接入。
- 邮件页使用列表和阅读区，搜索条件放进“筛选”；设置页分为收取设置、邮箱账号、同步记录。
- 使用统一的蓝色操作色、浅灰背景和本机字体，去掉邮戳装饰、大色块及导航圆点；保留原生键盘操作和手机侧栏开关。
- 新增 Streamlit 本地主题配置，工具栏使用 minimal 模式。没有引入依赖或更改后端、真实邮箱同步和模型访问范围。

验证：相关 79 项离线测试通过（12.85 秒），包括真实前端 AppTest、账号切换、搜索、同步设置、普通/Agent 对话、任务恢复、来源和正文显示。分栏后账号保存提示被刷新带走的问题已修复，并由既有保存测试验证。

浏览器验证运行实际 frontend/app.py，以合成 HTTP 数据替代后台：1440×1000 和 390×844 下没有横向溢出，输入框可见；首轮只出现一问一答，后续输入、跨页保留会话、新对话、点击阅读、搜索和清除搜索均通过。截图中的账号、邮件和回答均为演示内容，没有读取真实邮件或调用模型。

另外验证了方向键切换导航、筛选菜单、会话高级选项、账号详情，以及手机侧栏展开/收起和邮件阅读；没有横向溢出。

本轮未启动正式 API/前端服务，也未把演示预览作为真实邮件联调验收。最近一次全量回归结果见此前记录；本轮仅报告实际执行的 79 项相关测试。
