# 邮箱连接状态问答修复与验证

## 问题与结果

“你现在连接上了163了吗？”此前会落入通用澄清回复。旧的邮箱访问提示只在前端处理少数问法，后端和其他调用入口没有统一的状态能力；欢迎语也没有明确区分导入资料问答与真实邮件的本地处理。

此次将状态查询接入后端。普通对话、流式对话、Self-RAG、同步 Agent 和后台 Agent 任务均使用同一条状态路径。前端传递当前选中的账号 ID，后端按已认证用户检查归属。常见问法直接在本地回答；不常见的状态问法可通过现有意图分类器分类，该步骤仅接收当前问题，随后在本地构造状态答案。

## 修改清单

- 新增 `mailbox_status` 意图和只读状态接口 `GET /mailboxes/{account_id}/status`。
- 状态查询只读账号标识、授权版本、文件夹数量、解析计数及同步任务/计划元数据；不读取邮件正文、地址或加密授权码，不调用 IMAP 或邮件解析报告。
- 分别显示已保存的配置、本地快照数量、最近完成的同步记录、最近更新的同步任务和自动同步设置。历史成功记录不表示实时连接已验证，后续失败也不会被旧成功记录掩盖。
- 对多账号未选择、无权访问、QQ 与当前账号不匹配、无同步记录、后台同步未启用、连续失败暂停及状态不可读取分别作出说明。
- 统一欢迎语与对话资料范围提示。真实邮件仍仅支持本地收取、解析、阅读和搜索，未接入模型问答。
- 状态记录保留在用户可查看的会话历史中，但排除后续模型上下文、摘要、候选记忆以及模型历史工具，防止复用过时或私有状态。
- 移除旧前端状态拦截；没有修改邮件收取、发送、移动或归档流程。

## 验证结果

- 相关回归：113 passed。
- 完整离线回归：1462 passed，2 skipped，190 subtests passed；耗时约 3 分 11 秒。
- 前端通过真实 Streamlit AppTest 与合成 HTTP 响应验证普通、流式、Self-RAG、Agent 任务、账号切换、任务结果展示和服务离线提示。
- 后端覆盖截图原句、访问权限问法、同步数量查询、其他账号隔离、当前授权版本变化、旧成功后新失败、有效空邮箱及不可用存储。
- 使用 SQLite authorizer 验证状态查询不读取正文或凭据列、不写入数据库；离线测试禁止模型或邮箱网络连接。
- 在实际本地邮箱数据库上只读核对了新状态读取器；没有在这次状态验证中获取正文或连接邮件/模型服务。


## 验证范围与待验收事项

上述结果验证当前源码、隔离的 API 调用及前端测试环境。已有正式后端进程在验证时仍未加载新增状态接口，需要重启后再在外部浏览器验收；不能将源码测试通过等同于正式进程已更新。未验证通过真实邮件内容调用 DeepSeek，也没有开启此能力。

重启后开一个新对话，依次输入“你好”“你现在连接上了163了吗？”“我的邮箱有多少封邮件？”。预期欢迎语说明能力范围，后两句返回当前账号本地状态，不再显示通用澄清模板。原有历史回复不会被改写。
