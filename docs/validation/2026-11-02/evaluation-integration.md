## 方法与实际条件

- 原 30 题 `data/gold_chunks.json`，题目、ID、顺序与标签不变；每题按命中 gold 片段比例计算 context recall，再对题求平均。普通单题错误记零，保留在分母；未完成批次不提供完整聚合分数。
- `reference_time=2026-11-02T12:00:00+08:00`；“最近”仍是 `[now - 14天, now)`。`TOP_K=5`、`fetch_k=20`、`RERANK_TOP_N=3`；空候选等情况下数量可小于 20。
- BM25 与 RRF 开启；query rewrite 关闭。每题仅调用一次抽取/检索，V2 取候选前 3；V7 用原问题对同一候选序列执行 Cross-Encoder 重排。
- 抽取模型为 `deepseek-v4-flash`，thinking disabled；本次没有规划或 judge 模型调用。
- 本地嵌入模型 `BAAI/bge-m3`，revision `5617a9f61b028005a4858fdac845db406aefb181`；重排模型 `BAAI/bge-reranker-v2-m3`，解析到 revision `953dc6f6f85a1b2dbfca4c34a2796e7dde08d41e`。使用 CPU，重排 max_length 512、输入字符上限 1200。

- 依赖：sentence-transformers 5.4.1、transformers 5.6.2、torch 2.11.0、chromadb 1.5.8、openai 2.32.0。

## 代码处理与原因

1. **保留远端能力再移植本地增量**：沿用 main 的逐题会话隔离、评分材料、执行退出原因和历史报告，不用旧工作区整文件覆盖。
2. **统一参考瞬间**：`ExecutionScope` 新增带时区 `evaluation_reference_time`；原 date 字段仍是检索时区的午夜。日期与时间输入互斥，scope/显式参数/请求冻结值按 UTC 瞬间比较；不一致时拒绝，退出后恢复。规划提示、抽取、检索/统计和评分使用该时间。
3. **保住查询约束**：日期抽取失败继续报错，不清空日期；提示明确邮件发送日期与正文内容日期的区别。未增加日期语法、缺失年份猜测或抽取重试。
4. **模型故障只在可信边界分类**：仅把实际模型 SDK `APIStatusError` 的 401/402/403/404 转为安全专用异常。工具记录失败步骤后立即停止同轮剩余工具和后续规划/评分；评测停止批次，保留已完成记录。普通业务 HTTP 404 不触发此路径。
5. **评测证据完整性**：配对/检索评测的普通单题错误计零；永久服务错误、取消、预算/运行截止等保留 partial 并非零退出。Agent 评测的普通预算/截止错误仍按原有逐题失败语义处理，永久模型服务错误才进入本轮新增的停止传播路径。无效 gold 在模型调用前拒绝；重排 failed/circuit_open 不能算作 V7 成功；已有输出路径被拒绝，历史报告不覆盖。

方案由三位 Astra 子审查员分别审核后，经主审定案再实施；实现后交叉复审。复审发现的 gold 校验、重排降级误计成功和 Agent 报告覆盖问题均在全量回归前修复。

## 运行方式

在已配置模型、准备好本地权重和兼容索引的仓库中：

```powershell
python -B scripts/offline_tests.py tests -q
python -B scripts/paired_acceptance.py --reference-time '2026-11-02T12:00:00+08:00' --output '<一个不存在的新结果路径>'
```

配对脚本默认从自身所在仓库导入，可显式传 `--root`；它核实导入来源，记录代码、依赖、数据和索引哈希。为保持历史可比性，本次使用独立索引/输入副本和独立可写状态，原环境文件只载入进程，没有复制到新工作树。

旧索引的兼容性指纹包含 cleaner/chunker 的原始源文件字节，Git LF/CRLF 转换也会导致指纹不同。本次验证两处文件的规范化内容完全相同后保留旧索引对应的 LF 字节，Git 代码差异为零；没有绕过兼容性检查。其他环境若重建索引，应报告新的索引代和实测结果。

Agent 评测可单独使用 `scripts/run_agent_eval.py --reference-time '<带时区ISO时间>'`。旧 `--reference-date YYYY-MM-DD` 仍代表该日午夜：在“最近”的半开窗口中不包含参考日当天及之后的邮件，不能与中午参考时刻混用。不要将本页的检索参考时间自动替换原 105 题评测已约定的基准。
