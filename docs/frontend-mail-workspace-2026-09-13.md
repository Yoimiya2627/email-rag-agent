# 多邮箱工作台界面（2026-09-13）

这次界面以个人邮箱与助手对话为首页任务：浏览和阅读邮件时，右侧直接使用 Agent 对话栏，也可展开问答工作台继续同一会话。全局品牌「邮序」不绑定邮件服务商，账号切换固定在左侧；当前仅支持163连接，QQ等接入能力尚未实现。

## 页面分工

| 入口 | 用途 | 数据范围 |
| --- | --- | --- |
| 我的邮箱 | 浏览、搜索和阅读；立即同步；Agent 对话 | 邮件区使用当前账号的本地邮件；Agent 使用独立问答资料 |
| 同步与设置 | 添加账号、更新授权、选择文件夹、管理自动同步、查看解析报告与后台任务 | 当前账号的连接与同步设置 |
| 问答工作台 | 检索、总结、草稿、会话及证据核对；高级设置管理问答资料 | 独立问答索引，尚未接入已连接的真实邮箱 |

首页不显示原样例的5000封索引信息。真实邮件列表、正文和 Agent 对话栏默认展开；窄屏上下排列，将对话和输入框放在前面。搜索可按文件夹、未读、星标限定，并可返回全部邮件。不同账号保存各自的搜索、选中邮件和页码。

两个对话入口共用原有提交、流式输出、证据展示和后台任务逻辑。会话与模式可新建或恢复会话，选择普通、Self-RAG 或 Agent 模式；切换账号或页面不会自动提交对话。对话是独立资料的会话，不随账号切换而改成真实邮箱问答；不会把选中邮件、地址、正文或附件自动放入请求。

## 视觉方向

采用深海色导航（`#173238`）、浅灰画布（`#F1F5F6`）、白色阅读区（`#FFFFFF`）、青绿色操作（`#0F766E`）及灰蓝辅助文字（`#657780`）。「邮」字邮票是唯一品牌装饰，字体使用本机Bahnschrift、Segoe UI与中文回退字体；没有远程字体、图片或主题资源请求。

首页用紧凑标题、同步摘要、搜索和列表/阅读区，右侧常驻对话栏。参数、解析详情和开发资料从日常阅读路径中移开，保留其原有操作能力。表格正文仅在元数据位置与原文完全匹配时改为易读的单元格展示，不修改存储原件；不匹配时回退到原有纯文本。邮件标题、地址、正文和附件名称均防止被当成活动HTML/Markdown执行，打开邮件不改变服务器已读状态。

## 验证范围

- 合成Streamlit AppTest覆盖：首页邮件和对话并列、空账号下仍可对话、问答入口共用会话、跨页面与账号保留模式及历史、新会话不改变邮件选择、提交不附带邮箱上下文、后台任务显示偏好，以及原问答/审批/历史、搜索分页和安全正文展示流程。
- 外部Chrome的独立无头测试实例连接正在运行的 `127.0.0.1:8501`，实际执行搜索和返回全部邮件；没有连接或控制用户已有Chrome个人资料。
- 在1440×1000桌面与390×844窄屏检查布局，两种宽度无横向溢出，输入框均在首屏可见；桌面对话位于右侧，窄屏对话位于邮件区之前。实际输入框完成输入和清除检查，没有向真实模型提交。截图中的私人内容先以固定合成文字与样式遮罩替换，仅用于排版检查。界面支持可见键盘焦点与减少动画偏好；没有声称已完成所有辅助设备验收。
- 最终完整离线回归 **1372项通过、190项子测试通过**，耗时142.81秒；2项因当前Windows账户不能创建符号链接而跳过。另用独立合成探针验证普通、Self-RAG、Agent和SSE提交路径，未调用真实模型。审查发现的后台任务显示状态在切页后丢失已修正，并加入回归覆盖。
- Python编译、依赖一致性与Git差异检查通过。现有API就绪，自动同步仍按300秒运行且无连续失败；本轮没有重启后端或更改同步计划。测试和截图资料位于E盘，不上传私人邮箱资料。

## 部署与兼容

本轮修改前端及对应测试，没有改IMAP同步协议、后台调度或数据库格式，现有服务可直接加载新前端；在外部浏览器刷新页面即可。依赖声明将Streamlit最低版本与项目的1.49.1约束对齐；当前运行环境1.56.0满足要求，本轮未新增安装。容器key用于局部主题样式，参见[Streamlit 1.49容器文档](https://docs.streamlit.io/1.49.0/develop/api-reference/layout/st.container)。

真实邮件仍仅做本地收取、解析和搜索，AI问答权限没有扩大。QQ邮箱连接、发送、删除等能力不因这次界面调整而启用。
