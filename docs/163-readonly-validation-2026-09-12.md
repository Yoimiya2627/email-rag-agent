## 使用入口

打开 `http://127.0.0.1:8501` → 展开“163 邮箱 · 本地收取与解析” → 填写完整 `@163.com` 地址、客户端授权码 → “加密保存账号” → “测试连接并读取文件夹” → 选择文件夹和单次邮件数量 → “开始本地同步与解析”。授权码需由用户在 163 网页邮箱开启 IMAP 服务后取得，不能用网页登录密码代替。

同步结果可在同一面板查看，包括选定文件夹快照数量、已解析、失败、尚未下载、正文和附件质量、逐封正文与附件提取文本。新版在运行中每 2 秒自动刷新进度，任务结束时刷新最终报告并停止轮询。后台任务可停止或继续；重复同步优先补齐尚未下载的邮件。单次达到数量限制属于该批次结束，报告中的“尚未下载”不会冒充已同步。

## 实现范围

- 使用验证证书的 `imap.163.com:993` TLS 连接。支持时发送真实客户端 ID；EXAMINE 和 UID BODY.PEEK 只读抓取，不发 STORE、MOVE、EXPUNGE 或邮件发送命令。[Python IMAP 文档](https://docs.python.org/3.13/library/imaplib.html)
- 账号按 owner 和随机账号 ID 隔离；授权码使用 Windows 当前用户 DPAPI 加密，密文保存在 SQLite。公开 API、任务请求、日志和模型输入均不包含授权码。授权码重绑增加版本，旧版本任务在后续收取前停止。
- 文件夹 modified UTF-7 与引用处理、UIDVALIDITY、UID、内部日期、flags 和 RFC822.SIZE 核对；先检查大小，再受限读取并核对完整字节数。遇到服务器大小与实际 literal 不一致时，再独立请求完整 BODY，要求完整响应标记、精确 literal 长度、稳定的 UID/日期/报告大小及一致的已读字节前缀。每封上限默认 25,000,000 字节，未按固定差值放宽完整性校验。
- 原始 EML 按 SHA256 保存，逐封事务记录解析结果。进度以持久记录为准，不以最大 UID 推断所有旧邮件已处理。UIDVALIDITY 重置后新旧记录不会碰撞；旧代原件保留为历史。
- 中文主题/地址、RFC2047/RFC2231、UTF-8/GB18030、base64/quoted-printable、MIME alternative/related、HTML 表格和转发邮件均有相应处理。正文选择保留来源和覆盖信息，附件不会混入父邮件正文。
- TXT、CSV、JSON、HTML、日历文本（text/calendar、application/ics）、DOCX、XLSX、数字 PDF 可提取文本；日历附件仅展示文本，不生成或执行日历事件。Office 标为部分提取，公式只取已有缓存、不执行公式。PDF 保留页码和覆盖状态。[pypdf 文本提取边界](https://pypdf.readthedocs.io/en/6.18.1/user/extract-text.html)
- 扫描/无文本 PDF、加密 PDF、图片未 OCR、不支持格式和损坏内容有明确状态。不能把“已产出邮件记录”解释为全部附件已完整解析。
- 每封不可信 MIME/附件在单独进程解析，默认 30 秒；Windows 使用挂起启动后加入 Job Object，整组和单进程均限 768 MiB，超时/取消清理整个 Python 启动器及其子进程。解析工作进程禁止网络连接，不加载远端 HTML 图片。

真实验证确认并处理了以下问题或缺口：

1. 首次 5 封误报 incomplete_message：163 的 RFC822.SIZE 均比完整正文多报 4 字节。独立完整 BODY.PEEK 读取与首读原件逐字节一致，尾部检查无剩余内容。新增完整复核后，5 封均能同步；保留报告大小和实际大小的来源记录。
2. 页面停留在“正在同步”：原界面仅随交互重新查询。现运行时自动刷新，结束后刷新报告并关闭定时器。
3. 任务最终进度少计最后一封：原来在读取前发布进度；现在额外发布逐封已提交计数和结束计数，零新增同步也会归零。
4. application/ics 附件原本不支持：确认实际样本是有效日历文本后增加精确 MIME 别名；未知 MIME 加 .ics 扩展名仍不会强制解码。这是补充格式覆盖，不声称此前支持所有附件。
5. 附件成功提取原因 text_extracted 原本也进入“需要核查”列表：报告现在只把非 complete 附件的原因列入待核查，保留缺失字符集等真实提示。

当前样本未发现其他确认的正文或表格内容丢失问题。Office、PDF、图片 OCR、其他邮箱文件夹不能从这 30 封推导为已完成真实验收；上述格式的合成测试与真实样本结果分别记录。
